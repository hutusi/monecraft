## Verified facts the plan relies on

- Mob movement is **ground-clamped**: `tickMobs` sets `mob.position.set(nx, ground + mob.halfHeight, nz)` from `surfaceYAt` (mobAI.ts:328–337). Fish need a bypass branch.
- `world.isSolid` = not Air, not Water (voxelWorld.ts:53). Wheat/sapling are **solid painted full cubes** (atlas.ts:80–87 — "Like wheat, it's a full cube painted to read as a plant"). Kelp/coral must follow this pattern; a non-solid kelp couldn't be mined (`voxelRaycast` skips non-solid cells).
- Random ticks run handlers on `highestSolidY` tops (randomTicks.ts:76–83) — a kelp stack's top *is* the column's highest solid under non-solid water, so kelp growth fits the existing sampler unchanged.
- Structure derive-passes must be **seed-pure**: dedicated PRNG from `world.seed`, fixed draws per attempt, validation via `terrainTopY`/`getBiome` only (generation.ts:524–563, 636–732). Note: `coalRand` and `villageRand` **both use xor `0x85ebca6b`** — new PRNGs must pick fresh constants.

- `MOB_TEMPLATES.modelArgs` is `Parameters&lt;typeof createMobModel&gt;`, so an appended optional "fish variant" arg flows through; `mobVisuals` only animates gait when `legs.length === 4`.
